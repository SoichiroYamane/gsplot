# Publication example data

These tab-delimited numerical fixtures were generated by the project
maintainer with a self-authored numerical calculation program. They are not
experimental observations. The maintainer confirmed their authorship for the
public repository in [Issue #206](https://github.com/SoichiroYamane/gsplot/issues/206),
and the files are distributed under the repository's MIT license.

The directories contain normalized temperature-dependent quantities for the
calculation cases named in each filename:

- `gap/`: `T/Tc` and `Delta/kBTc`;
- `heat_capacity/`: `T/T_c` and `C_s/C_n`; and
- `yosida/`: `T/T_c` and `Y(T)`.

The original numerical calculation program is not included in this repository.
For documentation reproducibility, these fixtures are retained byte-for-byte,
the publication example records every transformation applied to them, and the
integration test verifies the plotted arrays against the files. A future change
to the numerical model or generated values requires a separately reviewed
scientific and visual update rather than an incidental example edit.
